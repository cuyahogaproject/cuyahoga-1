**************************************************************
Cuyahoga requires the ASP.NET Core Runtime 10 (on IIS: the ASP.NET Core Hosting Bundle).
**************************************************************

Installing Cuyahoga from the binary distribution (a published Web.Core site)

1. Requirements
    - IIS with the ASP.NET Core Hosting Bundle 10, or any host that runs ASP.NET Core 10.
    - A database server. Supported databases are
        - SQL Server (also Express and LocalDB)
        - PostgreSQL
        - MySQL

2. Extract the files to a directory on your local machine.

3. Create an empty database.

4. Set the connection string to the database that is created in step 3: create an
   appsettings.local.json next to appsettings.json (see Install.txt for the driver and dialect of
   PostgreSQL and MySQL):

    {
      "Cuyahoga": {
        "ConnectionString": "Server=(local);Database=Cuyahoga;User Id=***;Password=***"
      }
    }

    or set the environment variable CUYAHOGA_CONNECTIONSTRING.

    Make sure that the account that connects to the database for the first time
    has enough permissions to create the database!

5. Create a website or an application in IIS (application pool: No Managed Code) and set its home
    directory to the physical directory where the Cuyahoga files were extracted. Give the site write
    access to the data folder (App_Data, or the folder in "DataPath" in appsettings.json).

6. You are now ready to run the application. Open your browser and navigate to the site or
    application that is created in the previous step.

    At the first visit, the database will be installed automatically, and you'll be asked to set
    a password for the administrator (min. 5 characters!).  After that there is a choice to install
    additional modules and to create a sample site.  When everything is finished you can visit the web
    site adminstration pages. The url of the web site administration is
    http://SERVER_NAME/VIRTUAL_DIRECTORY/Admin/.

    The following steps are only required when no sample site is installed.

    In the web site administration, the first thing to do is creating a site. Make sure that the
    site url that you enter, corresponds with the real site url, including the virtual directory
    (for example, http://localhost/cuyahoga).
    When a site is created you can start adding pages (nodes) and sections.

Hints and tips:

- It's possible run the database install scripts manually if the installation fails for some
  reason. They are located in the Install/Core/Database directory.
- See Install.txt for the data folder and the search index settings.
